## Критерии завершения

- описание архитектуры, спецификация API и схема БД согласованы командой и переданы заказчику;
- спайки 2 и 3 подтвердили получение кадров агентом LiveKit и доставку событий через Kafka с задержкой < 1 с;
- выбраны архитектура модели и детектор лиц, результаты сравнения зафиксированы;
- макеты основных экранов и план тестирования готовы, прототип комнаты работает с токеном из meeting-service.

## Риски спринта

- спайк показал недостаточную скорость декодирования кадров на CPU – снижение разрешения подписки (слой simulcast) и частоты анализа;
- затягивание согласования ТЗ – разработка итерации 1 начинается по утвержденным разделам, остальное уточняется параллельно;
- объем макетов превышает оценку – приоритет экранам MVP (лобби, комната, панель эмоций).
