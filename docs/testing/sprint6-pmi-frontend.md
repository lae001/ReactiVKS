# EMO-97 — часть ПМИ для тестировщика

Авторская область — пользовательские сценарии frontend и наблюдаемые критерии.
Согласование совместной ПМИ, серверные метрики, качество ML и приёмку выполняют
ответственные участники команды. План основан на `test-plan.md`, REST/WS-контрактах
и сценариях UC-2–UC-7. Протокол текущего выполнения — `sprint6-frontend-status.md`.

## Паспорт каждого прогона

Записать дату, commit frontend и сервисов, адрес стенда, ОС, фактически запущенный
браузер и его версию, роли, устройства, режим камеры, сеть, состав сервисов.
Для подмен записать операции и характер данных. Использовать тестовые учётные записи.
В приложениях к протоколу исключить токены, пароли и действующие ссылки-приглашения.

## Ручные шаги для оставшегося объёма

Для Edge, Яндекс Браузера, Safari и физических устройств записать собственный
паспорт. Подтверждение обычного звонка пользователем уже принято в протоколе.
Проверять здесь дополнительные сценарии соответствующего браузера.

- Гость входит по приглашению, выбирает устройства и решение о согласии.
- Отключить и включить камеру/микрофон, проверить сохранение их состояния после reload.
- Обменяться сообщениями, выполнить модерацию и самостоятельное включение.
- Удалить гостя и проверить старый токен, завершить встречу и конечные экраны.
- Организатор проверяет историю, фильтры, настройки и скачивание серверных файлов
  после предоставления EMO-100. Safari по действующему плану покрывается в роли гостя.
- При доступном ML выполнить UC-4–5 той же встречи и приложить сервисные измерения.

Отметки выполнения этих шагов остаются пустыми до фактического прогона.
