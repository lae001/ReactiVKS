# Модель распознавания эмоций: обучение и выпуск

Каталог `ml/training`. Результат – ONNX-модель и карточка модели, которые подключает
[emotion-ml-service](emotion-ml-service.md).

## Задача

Классификация выражения лица на изображении кропа лица по 7 классам (порядок фиксирован в карточке модели):

`angry, disgust, fear, happy, sad, surprise, neutral`

Целевой показатель – accuracy ≥ 65 % на тестовой выборке открытого датасета; дополнительно – macro-F1 и
качество на собственной выборке кадров видеовстреч команды.

## Данные

| Датасет | Объем | Особенности | Использование |
|---|---|---|---|
| FER-2013 | ≈ 35 тыс., 48×48, оттенки серого | Шумная разметка, 7 классов | Обучение; **тест для целевой метрики** (PublicTest + PrivateTest) |
| RAF-DB (basic) | ≈ 15 тыс., цветные, выровненные | 7 классов, качественная разметка | Обучение, валидация |
| AffectNet | ≈ 280 тыс. (8 классов), цветные | Класс `contempt` исключается; сильный дисбаланс | Обучение (по доступности); валидация 7 классов |
| Собственная выборка | 3–5 ч записей встреч команды (с согласия) | Условия ВКС: сжатие, освещение, ракурсы | Только тест (и, возможно, калибровка) |

- Все изображения приводятся к единому препроцессингу **того же кода**, что и в сервисе (детекция YuNet → выравнивание →
  кроп 224×224, RGB; для FER-2013 – повторение канала). Код препроцессинга вынесен в общий модуль
  `ml/emotion_service/src/emotion_service/preprocessing.py` и используется обучением, чтобы исключить расхождение
  «обучение ↔ инференс».
- Дисбаланс классов (особенно `disgust`) – взвешенная функция потерь или сэмплер.
- Разметка собственной выборки – 3 разметчика (команда), итоговая метка большинством, кадры с разногласием
  исключаются. Кадры собственной выборки хранятся только локально у команды и не публикуются.

## Аугментации, приближающие данные к условиям ВКС

Горизонтальное отражение, небольшие повороты/масштаб, яркость/контраст/гамма (слабое освещение), размытие,
JPEG/WebP-компрессия с низким качеством (имитация VP8/H.264), понижение разрешения с последующим увеличением,
частичные окклюзии (Cutout). Библиотека – albumentations.

## Эксперименты

| Кандидат | Параметры | Ожидание |
|---|---|---|
| MobileNetV3-Large (ImageNet) | ≈ 5 M | Быстрый на CPU, базовая линия |
| EfficientNet-B0 | ≈ 5 M | Лучший баланс точность/скорость |
| ResNet-18 | ≈ 11 M | Надежная базовая линия |
| ConvNeXt-Tiny / ViT-S | ≈ 28 M / 22 M | Верхняя граница точности, вероятно только для GPU |

- Фреймворк: PyTorch + timm; конфигурации экспериментов – YAML в `configs/`; фиксированные seed.
- Журнал экспериментов – `ml/training/experiments.md` (таблица: дата, конфигурация, данные, метрики, ссылка на
  веса); опционально MLflow локально.
- Критерий выбора: accuracy ≥ 65 % на тесте FER-2013 **и** время инференса ≤ 15 мс/лицо на CPU демонстрационного
  сервера; среди прошедших – лучший macro-F1 на собственной выборке.
- Обучение – GPU участников, Google Colab, Kaggle, Yandex DataSphere (риск 8 устава: датасеты и веса храним локально).

## Экспорт и выпуск

1. `fer-train export --checkpoint … --opset 17` → `emotion-<arch>-v<N>.onnx`.
2. Проверка эквивалентности PyTorch ↔ ONNX Runtime (макс. отклонение вероятностей < 1e-3 на 500 изображениях).
3. Опционально – динамическая INT8-квантизация; принимается, если accuracy падает ≤ 1 п. п.
4. `fer-train evaluate` – отчет: accuracy, macro-F1, матрица ошибок, время инференса (CPU/GPU).
5. Карточка `model_card.json`:

```json
{
  "name": "emotion-effnetb0",
  "version": "1.0.0",
  "labels": ["angry", "disgust", "fear", "happy", "sad", "surprise", "neutral"],
  "input": {"size": [224, 224], "color": "RGB", "mean": [0.485, 0.456, 0.406], "std": [0.229, 0.224, 0.225]},
  "preprocessing": "yunet-align-v1",
  "metrics": {"fer2013_test_accuracy": 0.0, "fer2013_test_macro_f1": 0.0, "own_test_accuracy": 0.0},
  "datasets": ["FER-2013", "RAF-DB"],
  "license_note": "Только некоммерческое учебное использование"
}
```

6. Веса публикуются в GitHub Releases (и зеркале); `deploy/scripts/fetch-models.sh` скачивает нужную версию.
   Версия модели попадает в каждое событие `emotion.samples` и в отчет (`reports.model_version`).

## Детектор лиц

YuNet (OpenCV Zoo, ONNX, ≈ 0,1 M параметров, лицензия MIT) – быстрый на CPU, дает 5 опорных точек для выравнивания.
Запасные варианты: MediaPipe Face Detection, RetinaFace-MobileNet (через тот же интерфейс `FaceDetector`).

## Лицензии

Перед использованием каждого датасета и предобученных весов проверяется лицензия и фиксируется в реестре
компонентов (риск 10 устава). AffectNet и RAF-DB – только для некоммерческих исследований, что соответствует
учебному характеру проекта.
