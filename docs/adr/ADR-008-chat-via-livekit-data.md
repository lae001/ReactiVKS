# ADR-008. Чат через текстовые сообщения LiveKit без сохранения

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Автор:** Халецкий Д. Е.

## Контекст
Функция 6.3 требует текстовый чат во встрече. Требований к сохранению истории чата нет; хранение переписки
расширяет объем персональных данных.

## Решение
Чат реализуется текстовыми потоками LiveKit (тема `lk.chat`) и готовым компонентом чата; сообщения не сохраняются на
сервере, история живет во вкладке участника до конца встречи.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| **LiveKit data/text streams** | Ноль серверного кода, те же права доступа, что у встречи | Нет истории для опоздавших |
| Отдельный chat-service с хранением | История, модерация | Новый сервис и ПДн, не требуется |

## Последствия
- Опоздавшие участники не видят ранее отправленные сообщения (фиксируется в руководстве пользователя).
- При появлении требования к истории – добавляется подписчик на тему `lk.chat` в отдельном сервисе без изменения клиентов.
