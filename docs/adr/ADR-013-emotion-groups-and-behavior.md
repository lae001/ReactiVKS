# ADR-013. Пять групп эмоций для организатора, согласие / несогласие и усталость

- **Статус:** Предложено (требует согласования с заказчиком – изменение требований, список изменений устава)
- **Дата:** 11.11.2026
- **Автор:** Лесовой А. Е.

## Контекст

Модель распознает 7 базовых эмоций (ТЗ: accuracy ≥ 65 %). На встречах часть классов почти не встречается и
путается между собой: отвращение – 1,5 % выборки, в 24 % случаев распознается как гнев; страх – самый слабый
класс (F1 0,54), в 20 % уходит в грусть. Организатору при этом важнее поведенческие сигналы – согласен ли
участник, не устал ли он, – которых в 7 классах нет.

## Решение

1. **Модель и контракт остаются на 7 классах** (`probs`): требование ТЗ, сравнимость с FER-2013.
2. **Организатор видит 5 групп** (`groups`, `dominant_group` в `emotion.sample`): радость, удивление,
   нейтрально, **недовольство** = гнев + отвращение, **напряжение** = грусть + страх. Вероятность группы –
   сумма вероятностей ее классов; соответствие – `vks_contracts.ml_events.EMOTION_GROUPS`.
3. **Поведение** (`behavior`, нужна сетка лица MediaPipe) – правила по позе головы и мимике за скользящее
   окно ([behavior.py](../../ml/emotion_service/src/emotion_service/behavior.py)):
   - согласие – кивок, несогласие – покачивание головой: хватает одного обычного движения «туда и обратно»
     (наклон ≥ 5°, поворот ≥ 7° от начального положения и возврат к нему за 1,5 с, другая ось спокойна);
     сигнал держится 2,5 с;
   - усталость – PERCLOS (доля времени с прикрытыми глазами за 30 с, порог 15 %), зевки (рот открыт ≥ 1,2 с),
     опущенная голова; при очках вес век снижен.

## Обоснование (тест FER-2013, итоговая система)

| Набор | Accuracy | Macro-F1 |
|---|---|---|
| 7 классов | 0,702 | 0,685 |
| **5 групп** | **0,753** | **0,749** |
| 4 (негатив вместе) | 0,814 | 0,799 |
| 3 (позитив / нейтрально / негатив) | 0,824 | 0,797 |

Пять групп – компромисс: +5 п. п. точности при сохранении различия «раздражен» / «подавлен», важного
организатору. Три-четыре группы точнее, но теряют это различие.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Оставить 7 классов на панели | Без изменений требований | Шумные редкие классы, путаница для организатора |
| Переобучить модель на 5 классов | Немного проще модель | Ломает требование ТЗ и сравнимость с FER-2013; группы получаются суммой без потерь |
| **7 классов в модели, 5 групп в интерфейсе** | Требование ТЗ сохранено, точность групп выше | Нужно согласование отображения с заказчиком |
| Обучить модель замешательства / скуки (DAiSEE) | Прямые «учебные» состояния | Нет доступа к данным в срок проекта |

## Последствия

- Фронтенд: панель и отчет показывают группы, детализация – 7 классов по запросу; цвета групп – цвета
  главных классов (гнев, грусть).
- Поля `groups`, `dominant_group`, `behavior` – необязательные, без смены `version`; старые потребители их
  игнорируют.
- Распознавание жестов (симуляция: позы с дрожанием 1°, случайная фаза кадров, 200 повторов на точку):

  | Движение | Первая версия (≥ 2 разворота по 6°), 3 / 5 кадр/с | Текущая версия, 3 / 5 кадр/с |
  |---|---|---|
  | Один кивок 6° | 0 / 0 % | 66–82 / 88–95 % |
  | Один кивок 8° | 0 / 0 % | 87–99 / 100 % |
  | Два кивка 8° | 10–25 / 25–47 % | 81–98 / 96–100 % |
  | Покачивание 8° | 53–81 / 98 % | 97–98 / 100 % |
  | Доля кадров с ложным жестом: неподвижно (дрожание 1°) | 0 / 0 % | 0,8 / 0,7 % |
  | То же: разговор (плавное покачивание ±3°) | 0 / 0 % | 15 / 17 % |
  | Взгляд вниз или в сторону на 2 с, голова опущена | 0 % | 0–2 % |

  Первая версия почти не срабатывала на обычный кивок; текущая ловит один кивок ценой ложных срабатываний при
  энергичном покачивании головой во время разговора. Взгляд вниз короче 1,5 с с возвратом неотличим от кивка.
- Ограничения поведения: правила не проверены на размеченных записях; кивки надежнее при 5 кадр/с; усталость
  оценивается не раньше чем через 10 с; без сетки лица `behavior = null`. Проверка – собственная выборка
  (EMO-92).
