# ADR-006. React + TypeScript + Vite для клиентской части

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Автор:** Халецкий Д. Е.

## Контекст
Концепция допускает React или Vue.js. Нужны готовые компоненты видеовстречи и библиотека графиков.

## Решение
React 19 + TypeScript + Vite; `livekit-client` и `@livekit/components-react`; TanStack Query; Zustand; shadcn/ui +
Tailwind; Recharts; React Hook Form + Zod; типы API генерируются из OpenAPI.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| **React** | Официальные React-компоненты LiveKit, самая большая экосистема | – |
| Vue 3 | Проще порог входа | Нет официальных компонентов LiveKit – больше ручной работы с SDK |

## Последствия
- Часть UI комнаты (плитки, устройства, чат) берется из компонентов LiveKit и стилизуется.
- Контракт API проверяется на этапе сборки (`tsc`) за счет сгенерированных типов.
