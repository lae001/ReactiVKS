# UI-кит (EMO-18)

Стек: Tailwind CSS 4 + shadcn/ui (Radix), стиль `new-york`, конфигурация — `components.json`.

## Палитра

Токены объявлены в `src/index.css` (светлая и тёмная тема, формат oklch).

| Токен                                                   | Назначение                               |
| ------------------------------------------------------- | ---------------------------------------- |
| `primary`                                               | основные действия, акценты (индиго)      |
| `secondary`, `muted`, `accent`                          | вторичные поверхности и подсказки        |
| `destructive`                                           | удаление, отключение участника           |
| `emo-neutral/happy/surprise/sadness/anger/disgust/fear` | 7 классов эмоций для оверлеев и графиков |

Цвета эмоций не должны быть единственным носителем информации: рядом всегда подпись или иконка (доступность).

## Компоненты

Подключены: `Button`, `Card`, `Input`, `Label`, `Badge` (`src/shared/ui`). Новые добавляем по мере надобности (Dialog, Tabs, Tooltip, Toast, Select — спринты 2–4).

## Референсы интерфейсов ВКС

Список референсов для анализа: Телемост, Контур.Толк, Zoom, Jitsi Meet, Google Meet. Скриншоты и выводы — собрать вручную и положить в `docs/frontend/references/` (в рамках EMO-18 автоматически не выполнено).
